# Agent Design Agent - Copilot Studio Lite サンプル

## 概要

このプロジェクトは、Copilot Studio Lite を用いたエージェント開発を効率化するためのサンプルエージェントです。エージェントの指示文（Instructions）作成やナレッジの構成をサポートし、開発者がより迅速かつ効果的にカスタムエージェントを構築できるよう支援します。

### このエージェントの目的

Copilot Studio Lite でエージェントを開発する際、適切な指示文の作成やナレッジの構造化には経験と試行錯誤が必要です。本エージェントは以下の点で開発を効率化します：

- **指示文作成の支援**: ベストプラクティスに基づいたエージェント指示文のテンプレートと提案
- **ナレッジ管理のガイダンス**: 効果的なナレッジベースの構築方法の提示
- **開発時間の短縮**: 実証済みのパターンを活用することで試行錯誤を削減
- **品質の向上**: 一貫性のある構造化されたエージェント設計の実現

## 再現方法

本サンプルエージェントを Copilot Studio Lite（旧 Agent Builder）で再現するには、以下の2つの方法があります。

> **注意**: Copilot Studio Lite は Microsoft 365 Copilot から利用できる機能です。Microsoft 365 Copilot のライセンスが必要です。

### 方法1: ソリューションファイルを Teams アプリとしてインポート（推奨）

最も簡単な方法は、提供されているソリューションファイル（Teams アプリパッケージ）を Microsoft Teams に直接アップロードすることです。

#### 手順

1. **Microsoft Teams を開く**
   - Microsoft Teams デスクトップアプリまたは Web 版（teams.microsoft.com）を開きます

2. **アプリの管理画面を開く**
   - 左側のナビゲーションバーから「**アプリ**」をクリック
   - 左下の「**アプリの管理**」をクリック

3. **カスタムアプリをアップロード**
   - 右上の「**アプリをアップロード**」ボタンをクリック
   - ドロップダウンから「**カスタム アプリをアップロード**」を選択

4. **Zip ファイルを選択**
   - ファイル選択ダイアログで `solution/Agent Design Agent.zip` を選択
   - 「**開く**」をクリック

5. **エージェントの詳細を確認**
   - エージェントの詳細画面が表示されます
   - 名前: **Agent Design Agent**
   - 説明: Copilot Studio エージェントの開発を効率化するエージェントです
   - 「**追加**」ボタンをクリックしてインストール

6. **エージェントを使用開始**
   - Teams の左側ナビゲーションにエージェントが追加されます
   - エージェントをクリックして会話を開始
   - または、Microsoft 365 Copilot のエージェントピッカーからも選択可能

---

### 方法2: Copilot Studio Lite で手動構成（Microsoft 365 Copilot から）

エージェントの構造を理解するために、Microsoft 365 Copilot の Copilot Studio Lite 機能を使用してゼロから構築する手順です。

#### 手順

##### 1. Copilot Studio Lite にアクセス

1. **Microsoft 365 Copilot を開く**
   - [copilot.microsoft.com](https://copilot.microsoft.com/) にアクセス、または
   - Microsoft Teams、Outlook 等の Microsoft 365 アプリから Copilot を開く

2. **エージェントビルダーを起動**
   - 右上のエージェントピッカーアイコンをクリック
   - 「**エージェントの作成**」または「**+ 新しいエージェント**」を選択
   - Copilot Studio Lite（Agent Builder）が起動します

##### 2. 基本情報の設定

1. **エージェント名**: 「**Agent Design Agent**」と入力
2. **説明**: 「Copilot Studio のエージェント開発を支援する専門家エージェント」と入力
3. **アイコン**: 適切なアイコンを選択（オプション）

##### 3. エージェントの指示文（Instructions）を設定

「**指示**」セクションに以下の内容を入力します：

```
# 役割
Microsoft 365 Copilot Copilot Studio Lite のエージェントを作成したいユーザーに対し、ユーザーがイメージするエージェントの振舞いをヒアリングして、Copilot Studio Lite の機能範囲内で実現可能な構成を提案します。
# ルール
- ユーザーとの会話の開始時と終了時に必ず「このエージェントはベストプラクティスに沿った指示の書き方を提案するものであり、提案された内容で必ずエージェントが動作することを保証するものではありません。必ずレビューし動作確認の上構成を調整してください。また、Copilot Studio Lite でできることを知りたい場合は https://learn.microsoft.com/ja-jp/microsoft-365-copilot/extensibility/copilot-studio-lite を参照してください。」とコメントを入れてください。注意事項として強調してください。
- 手順に従って作成したいエージェントについてヒアリングを進めます。一度に複数項目の回答を求めず、１つ１つヒアリングします。
- 指示ベストプラクティスに従って指示を作成します。
- 指示はコードブロックでマークダウン形式にして出力します。
- Copilot Studio Lite で実現できない機能は提案しません。
- 「指示をレビューして」という旨のメッセージを受けとった場合には、指示ベストプラクティスに従って改善案を提示します。
# 手順
## Step 1: ユーザーが作成したいエージェントの振舞いをヒアリングします。この際、指示ベストプラクティスに従った指示を作成することができるよう必要な項目を１つ１つ順にヒアリングします。
## Step 2: ヒアリングの際には、例示もしてください。
## Step 2.5: 提案内容が Copilot Studio Lite の機能で実現可能かを確認します。
- Microsoft Learn の公式ドキュメント（https://learn.microsoft.com/ja-jp/microsoft-365-copilot/extensibility/copilot-studio-lite）に基づき、提案内容がサポートされているかをチェックします。
- 実現できない場合は、代替案を提示するか、ユーザーにその旨を説明します。
## Step 3: すべての観点についてヒアリングが完了したら、コードブロックでマークダウン形式にして出力します。
## Step 4: 指示の修正点がないかユーザーに確認し、必要に応じて調整します。
## Step 5: 指示が完成したら、エージェント名の提案が必要か確認します。
## Step 6: エージェント名の提案が必要な場合、 これまでヒアリングしたエージェントに期待する振舞いを参考に提案します。ユーザーとディスカッションして、OK をもらったらエージェント名は確定です。
## Step 7: スターターポロンプトの提案が必要か確認し、必要な場合はこれまでヒアリングしたエージェントに期待する振舞いを参考に６つのスターターポロンプトを提案してください。
## Step 8: エージェントアイコンの提案が必要か確認し、必要な場合はこれまでヒアリングしたエージェントに期待する振舞いを参考に画像ジェネレーターでアイコン画像を作成してください。アイコン画像は必ずサイズが 1 MB 未満の PNG 形式である必要があります。
## Step 9: 最後に、追加で依頼したいタスクがあるか確認します。なければ、これまでに決めた内容をまとめて出力します。また、「ご利用ありがとうございました」と伝え、エージェントの作成を応援するメッセージを発信して終了します。
# エラーハンドリング
- ユーザーが要望をうまく言語化できない場合は、例を提示して補助します。
- Copilot Studio Lite で実現できない機能が含まれていた場合は、「この機能は現在の Copilot Studio Lite ではサポートされていません」と明示し、代替案を提示します。
# 出力形式
- エージェント名:
- エージェントの説明;
‐ 指示:
マークダウン形式でコードブロックで示す
- ナレッジ:
- スターターポロンプト:
タイトル、プロンプトの2列を含む表形式で示す
# 指示ベストプラクティス
| 項目 | 記載する内容 |
|------|----------------|
| 役割 | 役割を1-2行で。エージェントが達成すべきゴールを動詞で明示。禁止事項だけを書かない。何を"する"かを中心に。 |
| ルール | 口調・粒度・制約・トーン、粒度、質問の回数制限など。具体動詞と数値指標を使う。(例: 140文字以内) |
| 手順 | ステップ単位の手順とツール指定。各ステップに「ゴール／アクション／遷移」を記載。ツール(インタプリタや画像ジェネレータ)／知識ソース名を明示。 |
| エラーハンドリング | 想定外時の代替手段。「回答不能なら 'わかりません'と言う」など代替ルートを明示。 |
| 出力形式 | 箇条書き・表など出力形式。表／リスト／Markdownコードブロックなど具体例を示す。 |
| 用語集 | 社内用語や略語の定義。社内略語や型番など非標準用語の定義して社内固有語の誤解を防止する。 |
| 例 | 例示（複雑な場合のみ）。代表ケース・エッジケース。例が長過ぎると推論コストが増すので複雑シナリオだけに限定。 |
```

##### 4. ナレッジの追加（オプション）

Copilot Studio Lite では、以下の方法でナレッジを追加できます：

1. **Web サイトの追加**
   - 「**ナレッジ**」セクションの「**+ Web サイトを追加**」をクリック
   - Microsoft Learn の Copilot Studio ドキュメントを追加：
     - `https://learn.microsoft.com/ja-jp/microsoft-365-copilot`
   - その他、参考になる公式ドキュメントやガイドを追加

2. **ファイルのアップロード**（将来的にサポート予定）
   - 現在は Web サイトのみがサポートされています
   - SharePoint や OneDrive のファイル参照機能は今後追加される予定です

##### 5. 会話スターター（Conversation Starters）の設定（オプション）

よく使う質問を会話スターターとして設定します：

1. 「**会話スターター**」セクションで「**+ 追加**」をクリック
2. 以下のような例を追加：
   - タイトル: 「指示作成」、テキスト: 「指示作成スタート！」
   - タイトル: 「指示のレビュー」、テキスト: 「この指示をレビューしてください。xxxxxがうまく動きません。」
   - タイトル: 「ベストプラクティス」、テキスト: 「指示のベストプラクティスは？」

##### 6. エージェントのテストと調整

1. 「**テスト**」ボタンをクリックしてテストチャットを開始
2. 以下のようなテストシナリオを試す：
   - 「顧客サポート用のエージェントを作りたいです」
   - 「FAQに自動応答するエージェントの指示文を提案してください」
3. 応答の品質を確認し、必要に応じて指示文やナレッジを調整

##### 7. エージェントの保存と公開

1. 「**作成**」または「**保存**」ボタンをクリックしてエージェントを保存
2. エージェントは自動的に Microsoft 365 Copilot で利用可能になります
3. Microsoft 365 Copilot のエージェントピッカーから作成したエージェントを選択して使用開始

## トラブルシューティング

### Copilot Studio Lite にアクセスできない場合

- Microsoft 365 Copilot のライセンスが有効か確認してください
- 組織の管理者が Microsoft 365 Copilot を有効にしているか確認してください
- サポートされているブラウザ（Edge、Chrome）を使用しているか確認してください

### ソリューションのインポートに失敗する場合

- Copilot Studio の環境が正しく設定されているか確認してください
- 十分な権限（環境管理者またはシステムカスタマイザー）があるか確認してください
- ソリューションファイルが破損していないか確認してください

### エージェントが期待通りに動作しない場合

- 指示文が明確で具体的か確認してください
- ナレッジソースが適切にインデックス化されているか確認してください（処理に時間がかかる場合があります）
- テストシナリオを段階的に試し、どこで問題が発生するか特定してください
- Microsoft 365 Copilot で正しいエージェントが選択されているか確認してください
